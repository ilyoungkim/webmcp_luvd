⚙️ 동작 방식
1순위 Chrome 내장 AI(window.LanguageModel) 사용 (최신 Chrome + 내장 모델 필요)
2순위 Google Gemini API 호출 (API 키 필요, 모든 Chrome에서 동작)
API 키는 gemini-key.js 파일에 저장되어 있습니다.

API 키 발급 방법 (aistudio.google.com에서 무료 발급):
1. aistudio.google.com 접속 → Google 로그인
2. "Get API key" → "Create API key"
3. 발급된 키를 gemini-key.js의 GEMINI_API_KEY에 입력
4. 확장 프로그램 다시 로드 후 질문
