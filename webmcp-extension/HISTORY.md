# 변경 이력 (History)

## v0.2.0.0 (2026-08-13)

### ✨ 주요 변경 사항

#### 1. AI 비서를 별도 창(window)으로 열도록 변경
- 기존에는 Chrome 툴바 **팝업**으로 열려 화면/탭을 전환하면 자동으로 닫히는 문제가 있었습니다.
- 이제 툴바 아이콘 클릭 시 **별도 창**으로 열려 화면 전환이나 탭 이동에도 유지됩니다.
- 헤더에 **✕ 닫기 버튼**을 추가하여 명시적으로만 닫을 수 있게 했습니다.
  - `manifest.json`: `default_popup` 제거, `windows` 권한 추가
  - `background.js`: `chrome.windows.create` 로 별도 창 생성/재사용/정리 로직
  - `popup.html`: 헤더에 닫기 버튼 추가
  - `popup.js`: 닫기 버튼 이벤트, 별도 창 크기(480×720) 자동 조정

#### 2. "연결 안 됨" 상태 표시 오류 수정
- 별도 창으로 열면 `chrome.tabs.query({ active, currentWindow })`가 **자기 자신의 창**을 반환해
  WebMCP를 감지하지 못하고 "⚠️ 연결 안 됨"으로 표시되는 문제가 있었습니다.
- `getTargetTab()` 헬퍼를 추가하여 **마지막으로 포커스된 일반 브라우저 창의 활성 탭**을 찾도록 수정했습니다.
- 적용 대상: `queryWebMCP`, `invokeTool`, `queryPageInfo`

#### 3. 화면 오른쪽 여백 문제 수정
- 별도 창(480px)으로 열리는데 `body`에 고정 `width: 440px`가 남아 **오른쪽에 40px 여백**이 생겼습니다.
- `popup.html`의 `body`를 반응형(`width: 100%`, `height: 100vh`)으로 수정하여 창에 꽉 차게 했습니다.

#### 4. 한국어 입력 시 메시지가 두 번 나뉘어 전송되는 문제 수정
- 한국어 IME 조합 중 Enter를 누르면 조합이 확정되는 `keydown`이 제출로 처리되어
  **첫 글자("개")가 먼저 전송**되고 나머지가 두 번째 메시지로 보내지는 문제가 있었습니다.
- `popup.js` Enter 핸들러에 `e.isComposing` 체크를 추가하여
  **IME 조합 중에는 제출하지 않고** 글자 확정만 하도록 수정했습니다.

#### 5. AI 답변 시스템 프롬프트 업데이트
- 두 시스템 프롬프트(내장 AI / Gemini) 모두에 **재회 가능성 진단지 제출 방법** 섹션을 추가했습니다.
  - 진단지 링크: `https://form.yonja.co.kr/?introounselor=448`
  - 제출 절차 및 신뢰 문구("무료 연애 및 재회 진단으로 아픈 사연의 가능성을 찾아드리겠습니다")
- 유튜브 채널 문구에서 URL 괄호 표기를 제거했습니다.

#### 6. WebMCPConfig 데이터 보강 (`yonja.html`)
- `service.get_info`: 실제 상품 가격(쇼핑몰 기준), 상담사 정보, 유튜브 채널/재회특강 영상 정보 추가
- `consultant.get_info`: 실제 상담사 6명(이승진, 허아윤, 권요셉, 장재원, 송기훈, 최희주) 정보 추가
- `diagnosis.submit`: 진단지 제출 방법 안내(`guide`)와 신뢰 문구 추가
